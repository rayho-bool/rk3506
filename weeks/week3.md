# 第 3 周：Linux 系统编程（12/14 ～ 12/20）

**目标**：把「换任何 Linux 平台都能用」的那一层打通。
**验收**：写一个「串口收数据 → 通过 TCP 转发」的小程序跑在板子上；**并用 Python 假上位机打它**（超时 / 重连 / 错误码）。
**投入**：16h

> 这周**任何情况下都不许砍**。它是唯一跨平台保值的一周，也是后面驱动、项目的地基。

## 任务清单

- [ ] 文件 IO：`open/read/write/ioctl`，非阻塞与 `select/poll/epoll`（写一个 epoll 主循环骨架）
- [ ] 进程：`fork` / `exec` / `wait`，亲手造一个僵尸进程再回收
- [ ] 线程：`pthread_create`、互斥锁、条件变量（写生产者-消费者）
- [ ] 进程间通信：管道、共享内存、消息队列（各写 20 行 demo 即可）
- [ ] socket：TCP 服务端（板子）+ 客户端（电脑）
- [ ] 串口：`termios` 配波特率/校验位，实测收字节
- [ ] 信号处理：`signal` / `sigaction`，做一个「Ctrl-C 优雅退出」
- [ ] 串口 → TCP 转发程序（本周主交付）
- [ ] Python 假上位机：超时、断线重连、校验、错误码（约 2h）
